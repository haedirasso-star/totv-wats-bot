# بوت واتساب الذكي — TOTV+

بوت مبيعات ودعم يردّ باللهجة العراقية، يعرض الباقات، يستقبل وصل التحويل
والإيميل، يحوّلهما إلى تلجرام بأزرار موافقة، وعند موافقتك **يُصدر كود تفعيل
حقيقياً من مخزون Supabase ويرسله للعميل تلقائياً**.

---

# ⚠️ أول شيء — أمان

المفاتيح التي أرسلتها في المحادثة **مكشوفة الآن**. قبل التشغيل:

| ما يجب فعله | أين |
|---|---|
| **غيّر كلمة مرور Supabase** — `12345678` ضعيفة جداً | Supabase → Authentication → Users → ⋮ → Reset password |
| ألغِ مفتاح Gemini وأنشئ بديلاً | aistudio.google.com → API Keys |
| ألغِ توكن البوت وأنشئ بديلاً | تلجرام → @BotFather → `/revoke` |

كل المفاتيح تُقرأ من ملف `.env` ولا يوجد أي سرّ داخل الكود.
**لا ترفع `.env` إلى GitHub إطلاقاً** (موجود في `.gitignore`).

# كيف يعمل

```
العميل يكتب على واتساب
        ↓
  البوت يفهم النية
        ↓
 ┌──────┴───────┐
 │              │
سؤال عام     يريد اشتراك
 │              │
Gemini      عرض الباقات (ثابت)
يجيب             ↓
             يختار باقة
                 ↓
           طرق الدفع
                 ↓
        يرسل صورة + إيميل
                 ↓
      ← تحويل إلى تلجرام مع أزرار
                 ↓
        أنت تضغط «✅ تفعيل»
                 ↓
   Supabase يحجز كوداً من المخزون
                 ↓
    الكود يصل للعميل على واتساب
```

## لماذا الأسعار ليست بالذكاء الاصطناعي؟

نموذج اللغة قد يخترع سعراً أو يَعِد بخصم. مسار المبيعات كله **آلة حالات
ثابتة** في `flows.js`، والذكاء الاصطناعي يجيب على الأسئلة الحرّة فقط.

أضفت أيضاً حارساً أخيراً: لو حاول النموذج كتابة شيء يشبه كود تفعيل،
يُستبدل تلقائياً قبل الإرسال.

# التركيب

## 1) شغّل ملف SQL

Supabase → SQL Editor → الصق `sql/04_bot_functions.sql` → **Run**.

ينشئ جدول `bot_orders` وأربع دوال، أهمها `bot_issue_code` التي تحجز كوداً
بـ `FOR UPDATE SKIP LOCKED` — فيستحيل إعطاء الكود نفسه لطلبين متزامنين.

## 2) جهّز واتساب

1. `developers.facebook.com` → أنشئ تطبيقاً من نوع **Business**
2. أضف منتج **WhatsApp**
3. من **API Setup** انسخ: `Temporary access token` و `Phone number ID`
4. الرمز المؤقت يعمل 24 ساعة فقط — للإنتاج أنشئ
   **System User Token** دائماً من Business Settings

## 3) جهّز المتغيّرات

```bash
cp .env.example .env
nano .env      # املأ القيم
```

`SUPABASE_SERVICE_KEY` = المفتاح من قسم **Secret keys** في Supabase.

> هذا هو المكان **الوحيد** الذي يجوز فيه استخدام المفتاح السرّي — لأنه
> سيرفر خلفي مغلق لا يصله أحد. لا تضعه في التطبيق أو صفحة الأدمن أبداً.

## 4) شغّل محلياً

```bash
npm install
npm start
```

افتح `http://localhost:3000/` — يجب أن ترى `status: running`.

## 5) ارفعه على استضافة

يعمل على أي منصة تدعم Node 18+. الأسهل مجاناً:

**Render.com** — New → Web Service → اربط GitHub
- Build: `npm install`
- Start: `npm start`
- أضف متغيّرات `.env` في Environment

**بدائل:** Railway · Fly.io · VPS مع pm2

> الخطة المجانية في Render تُنيم الخدمة بعد 15 دقيقة خمول، وأول رسالة
> بعدها تتأخر ~30 ثانية. للإنتاج استخدم خطة مدفوعة أو VPS رخيص.

## 6) اربط الويبهوكس

**واتساب:** Meta → WhatsApp → Configuration → Webhook
- URL: `https://نطاقك/webhook`
- Verify token: نفس `WA_VERIFY_TOKEN`
- اشترك في حقل **messages**

**تلجرام:** افتح هذا الرابط مرة واحدة في المتصفح:
```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://نطاقك/tg
```

# التشغيل اليومي

## املأ المخزون

البوت **لا يولّد أكواداً** — يسحب من مخزون جاهز. من صفحة الأدمن
(**🔑 أكواد التفعيل**) ولّد أكواداً لكل باقة مسبقاً.

راقب المخزون: `https://نطاقك/stock`

```json
{ "monthly": 24, "quarterly": 11, "yearly": 5 }
```

> إن نفد المخزون، تصلك رسالة على تلجرام عند الضغط على «تفعيل»:
> «لا توجد أكواد متاحة لهذه الباقة».

## ماذا يصلك على تلجرام

عند إرسال العميل وصلاً:

```
🧾 طلب اشتراك جديد
👤 أحمد
📱 9647701234567
📧 ahmed@gmail.com
📦 3 أشهر — 13,000 دينار
[صورة الوصل]

✅ تفعيل شهري   ✅ 3 أشهر
✅ تفعيل سنوي
❌ رفض الطلب    💬 مراسلة
```

اضغط زر الباقة → يُصدر الكود ويصل العميل خلال ثانية.

**الأزرار محمية:** تعمل من حسابك وحده (`TG_ADMIN_CHAT`). أي شخص آخر
يضغطها يُرفض ويُسجَّل في السجل — اختبرتُ هذا فعلياً.

# تعديل الأسعار والمعلومات

**كل شيء في ملف واحد:** `src/knowledge.js`

```js
export const PLANS = [
  { id:'monthly', name:'شهري', days:30, price:5000, priceText:'5,000 دينار' },
  ...
];
```

عدّل هنا فقط — يتحدّث في الرسائل الثابتة **وفي تعليمات الذكاء الاصطناعي
معاً**، فلا يمكن أن يتناقضا.

نفس الملف يحوي `APP_FACTS` (معلومات التطبيق) و`TROUBLESHOOT` (حلول
المشاكل) و`PAYMENT_METHODS` (طرق الدفع).

# ما اختبرتُه فعلياً

| الاختبار | النتيجة |
|---|---|
| طلب الأسعار → عرض الباقات | ✅ |
| اختيار باقة → طرق الدفع | ✅ |
| إرسال صورة → طلب الإيميل + تحويل لتلجرام | ✅ |
| إرسال إيميل → تأكيد + تحويل | ✅ |
| موافقة الأدمن → إصدار الكود وإرساله | ✅ |
| نفاد المخزون → رسالة واضحة | ✅ |
| رفض الطلب → طلب صورة أوضح | ✅ |
| تحقّق الويبهوك برمز خاطئ → رفض 403 | ✅ |
| أمر تلجرام من غير الأدمن → رفض | ✅ |
| استخراج الإيميل من نص عربي | ✅ |
| فهم "سنوي" و"3" و"شهري" | ✅ |

**ما لم أختبره:** الاتصال الفعلي بـ Gemini وواتساب وSupabase — يحتاج
مفاتيح حقيقية. اختبرتُ المنطق كاملاً باعتراض الشبكة.
